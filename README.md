# MECHANICA

Interactive 3D mechanical watch showcase for desktop and mobile browsers.

- 58 selectable components and a 12-stage exploded view
- Rotate, zoom, assemble and auto show
- Part Explorer with independent rotation and bilingual information
- Camera zoom preserved during rotation and restored after inspection

Phase 1 accepted; visual baseline frozen. This repository contains only the static website and its bundled dependencies.

GitHub Pages: deploy the main branch from the repository root. No build step or backend is required.

Mobile layout has been checked at 390×844; physical-device multi-touch and Android frame rate still require testing. This is visual mechanical art, not a manufacturing or engineering simulator.
